# AI IMAGE BADGE

Chromeで表示中の画像を確認し、画像来歴情報、端末内画像モデル、任意のOpenAI Content Provenance APIを使って判定理由付きバッジを表示する一般配布版Chrome拡張機能です。

バッジ表示：

- AI【SynthID】
- AI【C2PA】
- AI【モデル判定】
- AIかも／AIかも【C2PA】
- 非生成かも

通常のモデル判定、C2PA・メタデータ解析、周波数・ノイズ解析は端末内で実行します。OpenAIによるSynthID検証は任意・既定オフで、利用者自身のAPIキーを設定した場合だけ画像をOpenAI APIへ送信します。

## インストール

1. GitHub Releasesから `ai-image-badge-release-v0.12.0.zip` を取得して展開します。
2. Chromeで `chrome://extensions` を開きます。
3. 「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」から展開フォルダーを選択します。

Chrome内部ページ、Chromeウェブストア、新しいタブなど、Chromeが拡張スクリプトを許可しないページでは動作しません。

## 開発時の確認

```powershell
npm install
npm run check
```

3種類のONNXモデルはGit LFS対象です。clone前に `git lfs install`、clone後に `git lfs pull` を実行してください。Git LFSを使わずに取得すると、モデルが小さなポインターファイルのままになり、ローカル判定は動作しません。一般利用者向けのRelease ZIPにはモデル実体を同梱しています。
