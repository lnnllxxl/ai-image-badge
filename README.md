# AI IMAGE BADGE

Chromeで表示中の画像を確認し、画像来歴情報、端末内画像モデル、任意のOpenAI Content Provenance APIを使って判定理由付きバッジを表示する一般配布版Chrome拡張機能です。

バッジ表示：

- AI【SynthID】
- AI【C2PA】
- AI【モデル判定】
- AIかも／AIかも【C2PA】
- 非生成かも

通常のモデル判定、C2PA・メタデータ解析、周波数・ノイズ解析は端末内で実行します。OpenAIによるSynthID検証は任意・既定オフで、利用者自身のAPIキーを設定した場合だけ画像をOpenAI APIへ送信します。

## インストール

1. GitHub Releasesから `ai-image-badge-release-v0.13.1.zip` を取得して展開します。
2. Chromeで `chrome://extensions` を開きます。
3. 「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」から展開フォルダーを選択します。

Chrome内部ページ、Chromeウェブストア、新しいタブなど、Chromeが拡張スクリプトを許可しないページでは動作しません。

## 表示言語

Chromeの表示言語に応じて自動的に切り替わります。日本語は日本語、英語（en-US・en-GBなど）は英語で表示し、それ以外の未対応言語では英語を表示します。Webページ自体の言語やURLでは切り替わりません。Chromeの表示言語を変更した場合はChromeを再起動し、拡張機能の画面と対象ページを再読み込みしてください。

翻訳対象はポップアップ、設定、バッジ、判定理由・注意書き、APIログおよび操作テストページです。README・免責事項・プライバシーポリシー・提供された監査レポートは自動翻訳しません。翻訳メッセージは `_locales/en/messages.json` と `_locales/ja/messages.json`、共通処理は `i18n.js` にあります。

## 開発時の確認

```powershell
npm install
npm run check
```

3種類のONNXモデルはGit LFS対象です。clone前に `git lfs install`、clone後に `git lfs pull` を実行してください。Git LFSを使わずに取得すると、モデルが小さなポインターファイルのままになり、ローカル判定は動作しません。一般利用者向けのRelease ZIPにはモデル実体を同梱しています。
